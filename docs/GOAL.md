# Research goal

Establish a useful, checkable native effect-admission rule for recipient-aware computation reuse, then compose it with adaptive agent-observation noninterference under a precisely defined observer and resource model.

Reviewer evidence must include soundness within a stated supported domain, enforced admission/reconstruction, authentic complete-task controls, capable direct-evaluation and memoization baselines with full costs, and integrated timing/capacity/cancellation evaluation.

Current evidence supports selected compiler controls and conditional symbolic templates. A useful new general cache policy and end-to-end noninterference remain unestablished. Start with [FINAL_HANDOFF.md](HANDOFF.md).
