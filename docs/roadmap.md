## Reviewer expectations

The final contribution must show an enforced, useful native computation/effect boundary with a precise security claim. Ordinary memoization, receipts or an unchanged object hash are insufficient novelty or proof. A reviewer should be able to trace each claim to its supported domain, implementation, native controls and cost comparison.
